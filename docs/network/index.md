## 核心认知

- **IP 是无连接、逐跳转发的协议** — 每个路由器只知道下一跳，不知道整条路径，更不会把上一跳的信息随包带走
- **TTL** 是数据包的生存跳数计数器，每经一跳减 1，减到 0 触发 ICMP Time Exceeded
- **静默跳** — 路由器配置为不回复 ICMP Time Exceeded，traceroute 无法获知该跳的 IP。这**不代表路径不通**
- **DNS 与路由是分离的两层** — DNS 解决域名→IP 的映射，IP 路由解决数据包怎么走。ifconfig.me 不是操作系统工具，是外部 HTTP 服务
- **串行化时延集中在出口带宽最低的链路上**（通常是家庭上行），骨干网的高带宽链路段串行化时延可忽略
- **TCP 三次握手**保证连接建立在真实的请求上（防止旧 SYN 重放）；**四次挥手**的 TIME_WAIT 确保旧包消失后才关闭
